# PasswordManager Client

Десктопное приложение для генерации и управления паролями.

---
Возможности:
Выбор длины пароля, использование цифр, спецсимволов и заглавных букв.
Возможность сгенерировать сразу от 1 до 10 паролей за раз.
Копирование пароля в буфер обмена в один клик с визуальным откликом (ToolTip). Есть возможность скопировать сразу все сгенерированные пароли
Автоматическое сохранение последней сессии генерации в локальный JSON-файл.

---

Стек: Avalonia, ReactiveUI, .net8.0, Autofac.
